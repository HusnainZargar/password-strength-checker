# Password Strength Checker
This tool evaluates the strength of a password based on its length, character types (uppercase, lowercase, digits, and special characters), and estimates the time it would take to crack it using brute force with an NVIDIA RTX 4090 GPU. 💻✨
# Key Features:
### Password Analysis: Checks for uppercase, lowercase, digits, and special characters.
### Strength Rating: Rates passwords as Weak, Moderate, Strong, or Very Strong.
### Time-to-Crack Estimation: Provides an approximate time to brute-force the password.
### User-Friendly Interface: Clean and interactive console-based UI.
